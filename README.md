# rushilpillamari.github.io

> Personal portfolio — [rushilswork.github.io](https://rushilswork.github.io)

## About

Portfolio of **Rushil Pillamari**, Software Engineer based in Hyderabad, India. Built from scratch as a single-file static site with no frameworks or build tools.

## Stack

- Vanilla HTML / CSS / JS — zero dependencies
- Playfair Display · Syne · JetBrains Mono (Google Fonts)
- CSS Scroll Timeline API (progress bar)
- IntersectionObserver (scroll reveal)
- CSS custom properties for light/dark theming

## Features

- Preloader with animated R mark
- Character-by-character hero name reveal
- Custom cursor with contextual labels and glow
- Scroll-driven progress bar (CSS-native)
- Smooth scroll reveal with varied animations per section
- Light / Dark mode (persisted via localStorage)
- Fully responsive — mobile, tablet, desktop, large screens
- Film grain overlay
- Ghost section numbers
- Magnetic contact buttons
- Stat counter animation
- Active nav highlight
- Back to top button
- Hamburger mobile menu
- Logo easter egg (click R five times)

## Sections

- Hero
- About + Stats
- Skills
- Work Experience
- Projects (jobBot, Air Pollution Viz, Bandwidth Speed Test)
- Awards
- Contact

## Local Development

No build step needed. Just open `index.html` in a browser.

```bash
# Or serve locally
npx serve .
# Then visit http://localhost:3000
```

## Deployment

Hosted on **GitHub Pages** — auto-deploys on push to `main`.

```bash
git add .
git commit -m "update"
git push
```
