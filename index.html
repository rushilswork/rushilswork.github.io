jobBot: Automated Job Discovery Pipeline

A local-first AI-powered job discovery engine that searches 9 portals simultaneously, matches roles against your resume with natural language understanding, and tracks your entire application pipeline from discovery to offer.

FastAPI SQLAlchemy Playwright React 18 BeautifulSoup JWT + bcrypt SSE SQLite
View on GitHub
  • ◆Keyword discovery across LinkedIn, Naukri, Indeed, Monster, Glassdoor, Greenhouse, HiringCafe, Instahire, Uplers
  • ◆AI-powered natural language search over job listings
  • ◆Resume parsing & skill matching engine
  • ◆Real-time SSE feed for live scrape updates
  • ◆Pipeline tracking: New → Reviewed → Applied → Skipped
  • ◆JWT auth with bcrypt, httpOnly cookies
Quick Start
pip install -r requirements.txt
playwright install chromium
python main.py dashboard
→ localhost:8000
Behind the build

jobBot started as a personal problem: job searching across 9 different portals manually was exhausting. Built a local-first pipeline that scrapes them all simultaneously, parses your resume, matches roles by skill relevance, and tracks your entire application lifecycle. AI-powered natural language search means you can query listings conversationally rather than by keyword. JWT auth and httpOnly cookies keep everything secure locally.
